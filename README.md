------
## 📖 项目介绍
基于 HTML5、JavaScript 和 Tailwind CSS 开发的 Web 应用，旨在还原 2020-2024 期间常见的“健康码”用户界面。

------
## ✨ 功能特性
- 还原 UI：复刻了经典的蓝色背景、白色卡片设计、以及动态跳动的秒数显示。
- 多状态切换：🟢 绿码 / 🟡 黄码 / 🔴 红码 / 💉 已接种 / ❌ 未接种
- 家庭成员管理：模拟“切换到家人”功能，支持添加多名虚拟用户并在其间切换。
- 全离线运行：所有逻辑均在本地浏览器执行，不上传任何数据。
- 自适应设计：完美适配手机端与 PC 端显示。
